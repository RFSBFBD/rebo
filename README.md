# بياك | Bayaak.co — تجربة تسوق المتاجر المتعددة بالذكاء الاصطناعي
> **High-Fidelity AI-Powered Multi-Store E-Commerce Web Prototype**  
> مبني وفق الهوية البصرية المعتمدة (كحلي ملكي، ذهبي فاخر، بيج كريمي، خطوط عربية أصيلة Cairo/Tajawal).

---

## 🌟 نظرة عامة على المشروع

تم تطوير منصة **بياك (Bayaak.co)** كنموذج أولي تفاعلي عالي الدقة (High-Fidelity Interactive Prototype) جاهز للعرض المباشر على العميل وتدشين منظومة التجارة الإلكترونية للمتاجر المتعددة (Multi-Vendor Marketplace).

يعتمد التصميم بشكل مباشر على الهوية البصرية المستوحاة من الصورة المرجعية المرفقة:
1. **القسم الرئيسي "اكتشف من حولك"**: إعادة بناء دقيقة وفاخرة للبطاقات الثمانية الشهيرة بإطارات ذهبية ميتاليك وأزرار كحلية مدببة مع أيقونات ذهبية وإضاءة تفاعلية.
2. **المستوى الأول المطلوب**: عرض المتاجر في شبكات منظمة وعصرية داخل كل تصنيف (`/categories/:categorySlug`).
3. **المستوى الثاني المطلوب**: تجربة المتجر الفردي المتكاملة بكافة تفاصيلها (`/stores/:storeSlug`).
4. **مساعد بياك الذكي (AI Assistant)**: محرك توصيات ذكي باللغة العربية يقترح المتاجر والهدايا بناءً على الميزانية والمناسبة.

## 🗂️ التصنيفات الثمانية الأساسية (المطابقة للمرجع)

1. **حلويات** (`/categories/sweets`): شوكولاتة باتشي، كنافة حبيبة، كيك ديزاين، حلويات شرقية وغربية.
2. **زهور** (`/categories/flowers`): باقات ورد جوري هولندي، فازات رخامية، نباتات زينة، كروت إهداء.
3. **مولات وماركت وبقالة** (`/categories/supermarkets`): مقاضي المنزل، خضار وفواكه عضوية، ألبان، تموينات.
4. **مطاعم** (`/categories/restaurants`): مشاوي السلطان، بيتزا وباستا نابولي، سوشي فاخر، برجر واغيو.
5. **حيوانات** (`/categories/pets`): أطعمة قطط وكلاب مرخصة بيطرياً، رمل كربون، مستلزمات وألعاب.
6. **الجمال** (`/categories/beauty`): عطور نيش فرنسية أصلية، مكياج دور الأزياء العالمية، عناية كورية.
7. **إلكترونيات** (`/categories/electronics`): هواتف ذكية، سماعات عازلة للضوضاء، ساعات ذكية بضمان الوكيل.
8. **صيدلية** (`/categories/pharmacies`): أجهزة قياس الضغط والسكر، فيتامينات ومكملات غذائية، عناية طبية.

## ⚙️ إعداد بيئة العمل وربط الـ API

تم بناء هيكلية المشروع بنظام **طبقة خدمات منفصلة (Service Layer)** تضمن التبديل السلس بين **وضع العرض التجريبي (Demo Provider)** و **الـ API الإنتاجي (Production REST API)** بدون لمس مكونات واجهة المستخدم:

### المتغيرات في ملف `.env`:
```env
# رابط واجهة الـ API الإنتاجية (اتركه فارغاً للعمل في الوضع التجريبي التفاعلي)
VITE_API_BASE_URL=

# تفعيل أو تعطيل وضع البيانات التجريبية
VITE_USE_DEMO_DATA=true

# إعدادات المنصة
VITE_MARKETPLACE_NAME=Bayaak
VITE_DEFAULT_LOCALE=ar
VITE_CURRENCY=SAR
```

### بنية طبقة الخدمات (`src/services/api/`):
- `categoryService.ts`: استدعاء الأقسام مع معايير الفلترة والميتا داتا.
- `storeService.ts`: البحث عن المتاجر، الفلترة حسب (الأعلى تقييماً، الأسرع توصيلاً، الحد الأدنى للطلب، مفتوح الآن، توصيل مجاني).
- `productService.ts`: جلب منتجات المتجر، الفلترة حسب الأقسام الداخلية للمتجر، الترتيب حسب السعر والتقييم، جلب المنتجات ذات الصلة.
- `cartService.ts` / `CartContext.tsx`: إدارة السلة المتعددة المتاجر، تجميع الطلبات حسب المتجر، حساب رسوم التوصيل المنفصلة، وحفظ الحالة محلياً (`localStorage`).

## 🛒 الميزات التفاعلية المنفذة

1. **الصفحة الرئيسية (`/`)**:
   - بانر رئيسي فاخر مع شريط بحث تفاعلي.
   - قسم **"اكتشف من حولك"** مطابق ومطور عن الصورة المرجعية.
   - مساعد بياك الذكي (AI Assistant) مع أسئلة سريعة جاهزة وإمكانية إدخال استفسارات حرة.
   - قسم المتاجر المختارة الأكثر طلباً.
   - ميزات الثقة والأمان (توصيل مبرد، ضمان أصالة، دفع آمن).

2. **صفحة عرض متاجر التصنيف (`/categories/:categorySlug`)**:
   - مسار التنقل (Breadcrumbs).
   - هيدر التصنيف مع صور الغلاف والأقسام الفرعية التفاعلية (Tabs).
   - شريط فلترة وبحث حي داخل التصنيف.
   - شبكة متاجر متجاوبة بالكامل (4 أعمدة على الشاشات الكبيرة، 3 على المتوسطة، 2 على الأجهزة اللوحية، 1-2 على الجوال).
   - بطاقة متجر غنية تتضمن: لوجو المتجر، صورة الغلاف، التقييم، زمن التوصيل، رسوم التوصيل، حالة العمل (مفتوح/مغلق)، شارة العروض الحقيقية، زر التفضيل، وزر **"زيارة المتجر"** الذهبي.

3. **صفحة المتجر الفردي (`/stores/:storeSlug`)**:
   - هيدر هوية المتجر (شعار، غلاف، تقييم، ساعات العمل، رقم الهاتف، العنوان الجغرافي).
   - بانر العروض والمميزات الخاصة بالمتجر.
   - شريط تنقل الأقسام الداخلية للمتجر (أزرار قابلة للتمرير على الجوال).
   - فلترة وبحث حي داخل منتجات المتجر وترتيب الأسعار.
   - بطاقات المنتجات مع مؤشرات الخصم الحقيقي، حالة المخزون، وزر الإضافة السريعة.

4. **نافذة تفاصيل المنتج (Product Detail Modal)**:
   - معرض صور مصغرة وكبيرة.
   - خيارات مخصصة ديناميكية لكل تصنيف (مثل: حجم العلبة، نوع التغليف، لون المنتج، نوع الخبز، درجة النضج) مع تعديل فوري للسعر.
   - عداد كميات تفاعلي.
   - منتجات أخرى مقترحة من نفس المتجر.

5. **سلة التسوق والدفع التجريبي (Cart & Checkout)**:
   - سلة جانبية منزلقة (Slide-out Drawer).
   - فصل المنتجات وتجميعها حسب كل متجر (Multi-Vendor Segregation).
   - احتساب رسوم التوصيل لكل متجر بشفافية تامة.
   - نافذة إتمام الطلب التفاعلية مع بيانات العميل ووسائل الدفع (مدى، أبل باي، فيزا، دفع عند الاستلام) ورقم طلب حقيقي لتأكيد العملية.

## 📋 المتطلبات المستقبلية لربط الباك إند (Backend Roadmap)

عند جاهزية خوادم وقواعد بيانات العميل، يتطلب الانتقال للإنتاج فقط:
1. تزويد رابط الـ API في متغير `VITE_API_BASE_URL`.
2. ربط بوابات الدفع الإلكتروني المعتمدة في المملكة (مثل Tap Payments, Moyasar, أو HyperPay).
3. ربط نظام الخرائط وتحديد الموقع الجغرافي (Google Maps API أو Mapbox) لتحديد العناوين بدقة GPS.
4. نظام مصادقة المستخدمين (SMS OTP) عبر مزود محلي معتمد (مثل Unifonic أو Taqnyat).
